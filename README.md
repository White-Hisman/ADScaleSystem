# 老年痴呆症量表输入系统

基于 Qt 6 Widgets、C++、CMake 和 SQLite 的离线桌面应用，用于管理患者档案、随访记录及临床和神经心理量表数据。

## 项目目标

- 支持患者建档、查询和详情查看。
- 支持基线及后续随访管理。
- 支持医务人员、患者和家属参与量表录入。
- 支持量表草稿保存、校验、提交和历史查看。
- 支持本地查询统计、数据导出、备份恢复和多医院数据合并。
- 区分答案提供者、实际录入者和专业评定者。

## 技术栈

- C++：应用程序开发语言
- Qt 6 Widgets：桌面用户界面
- CMake：项目构建系统
- SQLite：本地数据库
- Git：版本管理与团队协作

## 环境要求

- Qt 6，包含 Qt Widgets 和 Qt SQL 模块
- CMake
- C++ 编译器：
  - Windows：Visual Studio/MSVC，或与 Qt 安装版本匹配的 MinGW
  - macOS：Xcode Command Line Tools
  - Linux：GCC 或 Clang，以及对应 Qt 开发包
- Git

Qt 版本、编译器和构建 Kit 必须相互匹配。Windows 用户可以在 Qt Creator 的 **编辑 > Preferences > Kits** 中检查 Kit 配置。

git clone https://github.com/White-Hisman/ADScaleSystem.git

git remote -v

## 使用 Qt Creator 构建

1. 启动 Qt Creator。
2. 选择 **文件 > 打开文件或项目**。
3. 选择项目根目录中的 `CMakeLists.txt`。
4. 选择已安装并配置好的 Qt Kit。
5. 点击配置项目，等待 CMake 完成。
6. 构建并运行项目。

## 使用命令行构建

以下命令适用于 Qt 和 CMake 已加入系统环境，或已正确配置工具链的情况：

```bash
cmake -S . -B build
cmake --build build
```

构建目录 `build/` 仅用于本地生成文件，不应提交到仓库。

## 数据与隐私约定

- 数据库保存在本地，具体位置由应用配置确定。
- 不得将真实患者资料、数据库文件或数据库备份提交到 Git。
- 测试和演示数据必须为虚构数据。
- CSV 用于查询结果导出，不作为完整数据库备份格式。
- 导入数据按全局唯一 ID 识别记录；内容冲突时生成冲突清单，不自动覆盖。
- 不根据姓名相似度自动合并患者。
- 量表答案状态应区分未填写、不适用、未查和有效答案。有效数值 `0` 不应被当作未填写。

## 量表数据约定

每份量表记录应关联患者、随访、量表代码和量表版本，并根据适用情况记录：

- 答案提供者：患者、家属／知情者或医务人员评定。
- 实际录入者：操作系统并录入答案的人。
- 评定者：实施专业评定的人员。
- 记录状态：未开始、草稿或已提交。
- 题项答案状态：未填写、不适用、未查或有效答案。

量表字段、条件逻辑、评分规则和计时要求应以经过核对的数据字典及量表操作说明为准。未经确认，不应自行修改量表含义或评分规则。

## Git 协作

项目采用成员开发分支和 PR/MR 评审流程：

- `main`：集成后的稳定分支。
- `A`：系统框架、主窗口、医院和随访功能。
- `B`：Qt 界面、患者管理和通用表单。
- `C`：数据库、查询统计、导入导出和备份恢复。
- `D`：临床资料与临床量表。
- `E`：神经心理、功能和睡眠量表。

基本工作流程：

```bash
git switch main
git pull origin main
git switch -c B

# 修改代码并进行构建、测试
git status
git diff
git add <相关文件>
git commit -m "feat: 添加患者详情页"
git push -u origin B
```

推送完成后，在代码托管平台创建 PR/MR，目标分支选择 `main`，填写改动内容和测试情况，评审通过后合并。后续在已有跟踪关系的分支上可使用：

```bash
git pull
git push
```

不要直接在 `main` 上开发。数据库结构、公共接口和量表字段发生变化前，应通知相关模块负责人并同步更新文档。

## 测试

如果项目配置了测试目标，可从构建目录运行：

```bash
ctest --test-dir build --output-on-failure
```

每个 PR/MR 应说明：

- 如何构建和运行。
- 修改了哪些功能。
- 执行了哪些测试。
- 是否涉及数据库结构、量表字段或公共接口变更。
